# TechEdu Solutions - Complete Website Template

A responsive static website template for:
- Software Development
- IT / Service Provider
- Educational Institute

## Pages
Home, Software & Services, Education, Portfolio, About, Contact.

## Customization
1. Replace "TechEdu Solutions" with your organization name.
2. Update phone, email and address.
3. Replace sample portfolio/projects.
4. Connect the contact form to Laravel/API/email.
5. Add your logo and images in `assets/`.
